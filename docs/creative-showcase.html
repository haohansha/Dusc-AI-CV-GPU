创意介绍

🎯
想解决什么问题
降低 Jetson Nano 的 AI 视觉识别嵌入式开发难度。围绕 Nano 做一个视觉项目，本应聚焦模型本身，实际上却被一堆琐碎的工程流程拖住：收集数据要手动复制整理、标注要切到 labelImg、训练要敲命令行、模型验证要写脚本、最后部署到 Nano 还要跨平台导出 TensorRT 引擎、CSI 摄像头管道还要单独适配。市面上找不到一个软件能把这些步骤串起来，新手往往卡在"流程"而不是"算法"上。
💡
为什么会想到做这个
项目原本是要做一个用于调控工厂通风系统的烟雾识别模型。但在开发过程中，我反复在不同工具之间切换：这里收数据、那里标注、再开终端训练、再写脚本部署 Nano——每一步都在打断思路。市面上虽有 Ultralytics、labelImg、TensorRT 各自的工具，却没有一个能"端到端"覆盖嵌入式视觉开发全流程的集成环境。于是我决定把这套流程自己封装成一个软件，让后来者不必再走一遍老路。
🚀
大概是什么产品
一套 Windows 桌面端 GUI 软件（PyQt5），内置五大模块：① 数据管理（统一 resource 目录 + 视频抽帧 + 内置 labelImg 风格标注编辑器）；② 模型管理（权重注册 + 版本信息）；③ 训练引擎（YOLOv8 配置可视化 + 一键启动 GPU 训练）；④ 推理验证（图片/视频/摄像头实时推理）；⑤ 边缘部署（Jetson Nano 环境检测 + TensorRT 引擎导出引导 + CSI 摄像头配置）。原本需要十几个工具交替完成的工作，现在一个窗口搞定。

目标用户及痛点

🔧
嵌入式开发工程师
需要把 PC 上训练好的模型部署到 Jetson Nano，但跨平台环境配置、TensorRT 引擎导出、CSI 摄像头适配等环节文档零散，反复踩坑。
🏭
工业 AI 方案商
为工厂定制视觉方案，希望有一套可复用的开发底座，避免每个项目都从零搭建数据管理和部署流程，缩短交付周期。

使用场景

从零开始做项目：打开软件 → 扫描文件夹批量导入素材 → 视频自动抽帧 → 内置标注编辑器画框 → 一键启动训练 → 模型自动注册 → 推理验证效果 → 导出 TensorRT 部署 Jetson，全程不离开主窗口；
迭代优化模型：在新场景采集数据后，直接在数据管理页补充标注、增量训练，旧模型版本可对比；
跨平台部署：在 Windows 上完成训练和验证，导出 .pt 模型后拷贝到 Jetson Nano，软件引导本地生成 TensorRT 引擎并测试 CSI 摄像头。

价值与意义

效率提升
把"十几个工具"压成"一个窗口"
  • 数据管理、标注、训练、推理、部署五大环节在一个 GUI 内完成，不再频繁切换工具
  • 内置 labelImg 风格标注编辑器，支持 Q 键快速画框、拖动调整、参数手动修改，标注效率成倍提升
  • 统一 resource 目录 + 媒体注册表，视频抽帧自动入库，告别手动整理文件夹
  • 训练配置可视化，超参数不再需要手敲 yaml，一键启动 GPU 训练并实时查看日志
降低门槛
让嵌入式 AI 开发"可复制、可教、可上手"
  • 把 Ultralytics、labelImg、TensorRT、GStreamer 等零散工具封装成统一体验，新手无需逐一学习
  • Jetson Nano 部署引导：环境检测脚本 + 参数预设 + 部署文档，按步骤即可完成跨平台部署
  • CSI 摄像头管道、TensorRT 引擎本地导出等坑点已内置解决方案，避免反复踩坑
  • 方案可复用于火焰、粉尘、缺陷检测等任何 YOLOv8 视觉任务，具备教学和工程推广价值
